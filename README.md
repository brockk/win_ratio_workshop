Win Ratio Workshop
================
The George Institute for Global Health authors
2026-09-07

## Intro

The materials in this repo were developed by researchers at The George
Institute for Global Health to train fellow trialists on the win ratio,
a method for analysing clinical trials using an hierarchy of outcomes.

## Downloading this code

You need to clone this code repository.

### Using RStudio.

File -\> New Project -\> Version Control -\> Git

In the Repository URL field, enter the url of this project:

<https://github.com/brockk/win_ratio_workshop>

Choose a suitable location, and click OK.

### Using git on the command line

Open the command line interface on your computer (Command Prompt on
Windows; Terminal on Mac or Linux).

Run the command `git` at the command line. If you get a help message
describing git’s usage, you have git installed. If you encounter a
message like `git not found`, then you don’t have git installed.
[Install git](https://git-scm.com/install/) and then come back here.

In the command environment, navigate to a suitable location and then
run:

`git clone https://github.com/brockk/win_ratio_workshop`

### Download as zip file from GitHub

Click the green button labelled `<> Code` above. Select `Download Zip`.
